## English

Adds camera distance, shoulder offset, height, custom FOV and running FOV controls to **REFramework → Script Generated UI → RE7 OTS Native**. Existing preferences and original defaults are retained; changes are saved across game restarts and F6 transitions.

F7 retains the selected shoulder spacing. FOV options apply while F6 is ON and continue to yield when REFramework writes FOV. F6 OFF returns FOV control to the game / REFramework.

Download **RE7_OTS_Native_v0.1.15_SteamDeck.zip** below and follow the included English or Korean guide. Exit the game before updating; for script-managed installs, run the installed uninstaller first. Settings, logs and models are preserved.

**Known issue:** Healing with Fullbright enabled can still darken the entire screen during the automatic first-person transition. This remains unresolved. The original CT and third-party models are not included.

## 한국어

**REFramework → Script Generated UI → RE7 OTS Native**에 카메라 거리·어깨 간격·높이, 사용자 지정 FOV와 달리기 FOV 설정을 추가했습니다. 기존 설정과 원본 기본값은 유지하며 변경값은 재시작·F6 전환 후에도 저장됩니다.

F7로 방향을 바꿔도 설정한 어깨 간격을 유지합니다. FOV 설정은 F6 ON 동안 적용하며 REFramework가 FOV를 쓰면 기존처럼 양보합니다. F6 OFF에서는 게임·REFramework가 FOV를 제어합니다.

아래 **RE7_OTS_Native_v0.1.15_SteamDeck.zip**을 받아 포함된 한·영 안내를 따르세요. 게임을 종료하고 업데이트하며, 설치 스크립트로 설치했다면 기존 제거 스크립트를 먼저 실행하세요. 설정·로그·모델은 유지됩니다.

**알려진 문제:** Fullbright 사용 중 치료 시 자동 1인칭 전환 동안 화면 전체가 어두워지는 문제는 아직 해결되지 않았습니다. 원본 CT와 다른 제작자의 모델은 포함하지 않습니다.
