## English

Adds automatic GitHub Releases for version tags and includes both English and Korean installation guides in the Native ZIP. Gameplay remains based on 0.1.12.

Download **RE7_OTS_Native_v0.1.14_SteamDeck.zip** below. Exit the game and follow the included guide. For a script-managed update, run the installed uninstaller before the new installer; settings, logs and model files are preserved.

Settings: **REFramework → Script Generated UI → RE7 OTS Native**.

**Known issue:** With Fullbright enabled, healing can still darken the entire screen during the automatic first-person transition. Brightness returns when third person resumes. This release does not resolve that issue.

The original CT and third-party models are not included.

## 한국어

버전 태그에서 GitHub Release를 자동 게시하도록 구성하고, Native ZIP에 한국어·영어 설치 안내를 함께 포함했습니다. 게임 동작은 0.1.12 기준입니다.

아래 **RE7_OTS_Native_v0.1.14_SteamDeck.zip**을 받으세요. 게임을 종료하고 포함된 안내를 따르세요. 설치 스크립트로 업데이트한다면 기존 제거 스크립트 실행 후 새 설치 스크립트를 실행합니다. 설정·로그·모델 파일은 유지됩니다.

설정 위치: **REFramework → Script Generated UI → RE7 OTS Native**.

**알려진 문제:** Fullbright 사용 중 치료 아이템으로 자동 1인칭 전환되면 화면 전체가 어두워졌다가 3인칭 복귀 시 다시 밝아질 수 있습니다. 이번 버전에서 해결된 문제는 아닙니다.

원본 CT와 다른 제작자의 모델은 포함하지 않습니다.
