# 검증 결과 — RE7 OTS Diagnostics 0.1.0

## 수행한 검증

Windows x64 DLL 빌드에 성공했습니다. 내보내기 함수 2개, 시스템 DLL 의존성 2개, x64 unwind/재배치 정보를 검사했습니다. 외부 C/C++ 런타임에 의존하지 않습니다.

C 핵심 검사 30개, Python unittest 18개가 모두 통과했습니다. 여기에는 무작위 마스크 검색 500회, 전체 78개 패턴의 청크 경계 비교, SHA-256 비교, 원본 CT 재추출, Windows PE 구조 확인, 모의 Win32 호스트와 Lua 상태 UI 검사가 포함됩니다. 해당 빌드 환경에서 건너뛴 테스트는 없습니다.

추가로 모의 호스트의 정상·변경·중복·없음·읽기 실패·파일 거부·잘못된 파일·재검사·로그 생성 실패·로그 쓰기 실패 10가지 상황을 AddressSanitizer/UndefinedBehaviorSanitizer로 실행했습니다. 메모리 오류가 보고되지 않았고 합성 게임 파일·합성 메모리가 변경되지 않았음을 검사했습니다.

같은 소스와 도구로 두 번 빌드한 DLL의 SHA-256이 일치했습니다. 구체적인 출력은 source 패키지의 evidence/에 있습니다.

## 아직 검증하지 않은 것

실제 Windows/Proton 로더로 이 DLL을 로드하지 않았습니다. 실제 REFramework, RE7, Steam Deck 장비에서의 실행·UI·안정성은 검증하지 않았습니다. Linux 모의 호스트 시험은 이 실기 시험을 대체하지 않습니다.

3인칭 기능은 구현하지 않았습니다. 카메라·사격·벽 충돌·컷신·포인터 체인 의미·모드 충돌의 실제 원인은 검사만으로 확정하지 않습니다. BYTE_MATCH_ONLY 또는 COMPLETE를 호환 확정으로 해석하면 안 됩니다.
