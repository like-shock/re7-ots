# RE7 OTS Explore v0.3.0

탐색용 카메라 시제품입니다. 기존 관찰기와 달리 실제 카메라 위치를 바꿉니다. 켜고 평소처럼 플레이하면 상태와 카메라 로그를 자동 기록하므로, F7 단계 전환이나 F8 기록 시작은 필요하지 않습니다.

## 설치

1. 게임을 완전히 종료합니다.
2. 아래 구버전 파일이 있다면 게임 폴더의 `RE7_OTS_backup/`으로 옮깁니다. 보관 폴더는 `plugins/`와 `autorun/` 밖에 만드세요.
   - `reframework/plugins/RE7_OTS_Observer.dll`
   - `reframework/autorun/re7_ots_observer.lua`
   - `reframework/plugins/RE7_OTS_Diagnostics.dll`
   - `reframework/autorun/re7_ots_diagnostic_status.lua`
3. 설치 ZIP의 `reframework/` 폴더를 `re7.exe`가 있는 폴더에 합칩니다.

설치되는 파일은 다음 두 개입니다.

```text
reframework/plugins/RE7_OTS_Explore.dll
reframework/autorun/re7_ots_explore.lua
```

현재 작동하는 REFramework, RELit, Proton 및 Steam 시작 옵션을 유지하세요. 새 `dinput8.dll`, Cheat Engine, 별도 실행 파일은 필요하지 않습니다. v0.2.1 카메라 수정본을 먼저 설치할 필요도 없습니다.

## 사용

Steam Input 버튼 하나에 키보드 **F6**을 지정하세요. 예전 F8 버튼을 F6으로 바꿔도 됩니다. 시작할 때 카메라는 항상 OFF입니다. 세이브를 불러오고 REFramework 메뉴를 닫은 상태에서 F6을 짧게 누르면 켜지며, 다시 누르면 꺼집니다.

메뉴의 `Script Generated UI → RE7 OTS Explore v0.3.0`에서도 `Exploration camera (F6)`를 켤 수 있습니다. 메뉴가 열려 있는 동안은 적용을 잠시 멈춥니다. `Distance`, `Shoulder`, `Height`로 거리를 조절하고 `Swap shoulder`로 어깨 방향을 바꿉니다. 조절값만 저장되며 ON 상태는 저장되지 않습니다.

조준·인벤토리·상호작용 신호, 로딩 중 잘못된 값 또는 게임 포커스 이탈을 감지하면 적용을 멈춥니다. 정상 상태가 0.5초 이상 안정되면 다시 진입합니다. 상태 샘플링에 따른 짧은 지연이 있으므로 전투나 연출 장면에서는 F6으로 끄세요.

처음에는 잠시 `VALIDATING`이 표시됩니다. 기존 사용자 로그에서 확인한 실행 파일 SHA-256과 PE 정보에 맞는 빌드만 동작합니다. 게임 업데이트 등으로 `UNSUPPORTED`가 표시되면 해시 제한을 바꾸지 마세요.

| 표시 | 의미 |
|---|---|
| OFF | 사용자가 끈 상태 |
| WARMUP / WAIT / PAUSED 계열 | 상태 또는 카메라가 준비될 때까지 대기 |
| ENTERING / ACTIVE | 위치 적용 진입 / setter 호출 후 좌표 확인 성공 |
| FAULT 계열 | 복구 실패 또는 다른 위치 변경과의 충돌 감지. 자동으로 OFF 유지 |
| ERROR 계열 | 설정이나 로그 파일 오류 |

`ACTIVE`는 카메라 좌표 확인 결과입니다. 렌더링된 화면의 품질을 판정하는 표시가 아닙니다. 다른 카메라 변경과 충돌하면 현재 외부 위치를 덮어쓰지 않고 OFF로 멈춥니다. 같은 문제가 계속되면 켜기를 반복하지 말고 그 상태의 로그를 전달해주세요.

## 이번 버전에서 볼 부분

별도 순서표 없이 잠깐 이동하고 시점을 돌려보세요. 평소 플레이 중 조준·인벤토리·로딩을 거쳤을 때 시점이 돌아오는지도 함께 볼 수 있습니다. 편한 실행 모드에서 진행하시면 됩니다. 다른 모드로 바꿔 같은 검사를 반복할 필요는 없습니다.

이 버전의 범위는 **탐색 카메라 이동과 복귀**입니다. 벽 충돌 방지, 캐릭터 몸체·머리 표시 패치, 3인칭 탄도 보정, DLC 대응은 포함하지 않습니다. 따라서 벽을 뚫거나 몸체가 일부 보이지 않을 수 있으며, 모든 연출 장면을 자동 판별하지는 않습니다.

## 피드백과 로그

좋았던 점이나 불편한 움직임을 간단히 알려주세요. 문제가 있으면 게임을 종료한 뒤 아래 폴더의 `play_0.jsonl`, `play_1.jsonl` 중 존재하는 파일을 함께 보내주세요.

```text
reframework/data/RE7_OTS_Explore/
```

로그는 자동 시작하며 두 파일을 번갈아 사용합니다. 파일당 최대 2 MiB, 합계 최대 4 MiB로 오래된 내용은 덮어씁니다. 문제 직후 종료하면 최근 기록을 보존하기 쉽습니다. `status.json`만으로는 플레이 흐름을 알 수 없습니다. 로그가 없으면 메뉴에 표시된 상태 문구만 알려주셔도 됩니다.

기록에는 좌표, 플래그, 카메라 객체 식별값, 적용·복구 결과가 들어갑니다. native 값과 카메라 값은 서로 다른 시점의 관찰입니다. 모니터는 한 게임 실행당 최대 12시간 동작합니다.

제거하려면 게임 종료 후 이번에 추가한 DLL/Lua 두 파일만 밖으로 옮기세요. 실행 중 DLL 교체나 재로드는 하지 마세요.

## 개발 검증

48개 자동 검사, C 핵심 검사 30개와 기존 관찰기 시나리오 12개를 통과했습니다. 새 모니터의 12가지 OS 모의 시나리오는 48개 검사에 포함됩니다. 배포 Lua의 켜기·500프레임 유지·끄기 복구와 DLL/Lua 재빌드 일치도 확인했습니다. 실제 Steam Deck 화면과 조작감은 이번 플레이에서 확인할 부분입니다.
